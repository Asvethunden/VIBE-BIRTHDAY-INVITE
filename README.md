# The Golden Legacy — Birthday Invitation Website

A four-page birthday invitation website for Light Yagami's 18th birthday, built with HTML, CSS and JavaScript.

## Pages
- `index.html` — animated envelope, invitation card and navigation options
- `menu.html` — proposed celebration menu
- `about.html` — birthday honouree introduction
- `schedule.html` — proposed event timeline

## Design
The design keeps the original warm beige/ivory direction and elevates it with black, champagne gold, elegant typography and decorative details. No human faces or portraits are used.

## Run locally
Open `index.html` in a web browser. Keep all files in the same folder.

## Before submission
Review the suggested menu and proposed timings, replace anything that is not confirmed, add your own original Lab 11 cake image if desired, and record the prompts you actually used in `prompts.docx`. Do not claim that unverified event details are final.
